# Sistema Web de la Posta de Salud Comunitaria

Proyecto integrador de la unidad didáctica **DSI406 · Tecnología Backend** (IES Público Túpac Amaru).

## Requisitos del entorno
- PHP 8.3 o superior (con extensiones `pdo_pgsql` y `pgsql` activas)
- Composer 2.x
- PostgreSQL 18
- Node.js y NPM
